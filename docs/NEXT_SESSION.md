## 3. Грабли этой сессии
- PowerShell: в строке в двойных кавычках обратная кавычка — escape (`` `r `` → CR, `` `b `` → backspace, `` `0 `` → NUL):
  markdown с `code` так писать нельзя — только файлом через Write или одинарные кавычки.
- `open_application("Electron")` в computer-use запускает ПУСТОЙ Electron, а не Джарвиса.
- vm-стенд для page-функций: таймеры в песочнице — заглушки, иначе верхний код SW держит `node --test` вечно.
