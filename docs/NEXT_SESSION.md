## 2. 🔴 ОТКРЫТАЯ РАЗВИЛКА — нужно решение владельца, код НЕ трогали

**`app_launch` — дверь без замка, и рецепты теперь штатно ведут в неё.**

Факт (подтверждён прогоном): `app_launch` отсутствует в `URL_NAV_TOOLS` (`dispatch.ts`), SSRF/URL-гарда на
нём нет; фильтр схем `REPLAY_SAFE_URI_SCHEMES` стоит ТОЛЬКО на слепом реплее навыка. Шесть рецептов
(`ms-settings:`, `steam:`, `tg:`, `vscode:`, `com.epicgames.launcher:`) переписаны с `browser_open` на
`app_launch`, то есть инъекция со страницы («открой `ms-msdt:/id PCWDiagnostic …`») исполняется одним вызовом.

Три варианта: (1) allowlist схем на прямом пути — сломает эти шесть рецептов; (2) денилист опасных
(`file:`, `ms-msdt:`, `search-ms:`, `shell:`, `res:`) — денилист в проекте признан принципиально неполным;
(3) оставить осознанно и записать, как с античитом.

**Рекомендация ассистента (не решение):** гибрид «allowlist по КЛАССУ обработчика» — резолвить схему через
реестр (`HKCR\<scheme>\shell\open\command`) и пускать без вопроса только схемы, чей обработчик — установленное
приложение вне `System32`/LOLBin (`msdt.exe`, `rundll32`, `mshta`, `wscript`, `powershell`, `cmd`, `explorer`
для `search-ms:`); `file:` — блок; всё остальное — через §14-подтверждение. Это не денилист строк, а резолв из
источника истины ОС, как у `app-resolve`. Пока решения нет — код не трогать.

## 5. Грабли этой области (проверено на себе)

1. **Рецепт, который не матчится, ХУЖЕ отсутствия рецепта** — проверять прогоном против фикстуры реального инвентаря.
2. **Индекс Windows врёт молчанием:** папка внутри профиля может отсутствовать в индексе; CONTAINS слеп для типов без IFilter (`.md`). Проба покрытия — перед КАЖДЫМ «не найдено».
3. **Две эвристики одного и того же = пинг-понг между инструментами** (fs_read↔file_view). Одна таблица сигнатур на клиент — `fs-content.looksBinary`.
4. **prune зовётся ДО показа модели** — всё, что режет историю после `convo.push`, обязано защищать хвост.
5. **Дефолт env = дефолт функции → проводка невидима тестам.** Тест ПЕТЛЁЙ с двумя разными значениями env.
6. **Bash-команды длиннее ~30 КБ падают с `ENAMETOOLONG`** — большие правки писать файлами (Write) и python-скриптами в scratchpad.
7. **Не больше 5 агентов** — считать от лимита, не от желаемой тщательности.
8. Пункты 3–8 утреннего списка (Windows-утилиты только `builtin`, паспорт режется с хвоста, «новое поле = у легаси его нет», короткие токены в гейтах, «не предлагать то, что уже есть», параллелить по файлам) остаются в силе.
