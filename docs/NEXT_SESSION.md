## 3. Грабли облачной сессии
- Контейнер облака может пересоздаться посреди работы (процессы гибнут, диск и git живы) — коммитить промежуточно.
- Воркфлоу пускает не больше `CPU − 2` агентов одновременно (в облаке 4 CPU → 2); третий ждёт в очереди.
- Стенд расширения под root требует `--no-sandbox` (сделано в `cdp-harness.mjs` только для root).
- Фикстура не той формы — снова главный источник пропусков (раунд 2: одобрение по склейке ref-хинта).
