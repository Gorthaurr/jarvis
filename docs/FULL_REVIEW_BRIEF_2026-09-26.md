## Эталон: как устроены руки у Claude сейчас (сверяйся с этим)
**Computer use (рабочий стол):**
- Снимок экрана с параметром масштаба (дешёвый обзор) + ZOOM области в полном разрешении для мелкого текста;
  координаты кликов — всегда в системе полного снимка.
- BATCH: последовательность действий (клик → ввод → Enter → снимок) одним вызовом, стоп на первой ошибке; снимки
  внутри батча возвращаются. Сильно режет число раундов.
- Полный набор ввода: click/double/triple/right/middle, drag, scroll, hold_key, mouse down/up, key-комбо, type
  (многострочный — через буфер), чтение/запись буфера, позиция курсора.
- Мультимонитор: выбор дисплея для снимков; открытие приложения по имени; allowlist приложений с уровнями доступа
  (read / click / full); чужие окна маскируются на снимке.
- Режим «научи» (пошаговые подсказки поверх экрана).
- Windows-MCP (аналог): снимок с деревом UI и интерактивными элементами С КООРДИНАТАМИ, опциональной картинкой и
  сеткой; Click/Type по метке элемента (clear, press_enter); App launch/switch/resize; Shortcut; Scrape.

**Браузер (Claude in Chrome / встроенный браузер):**
- `read_page` — дерево доступности с `ref_N` у интерактивных элементов, фильтр interactive/all, глубина, фокус на
  поддерево (`ref_id`), кап символов.
- `find` — поиск элементов по описанию/подстроке → до 20 ref.
- `form_input` — установить значение по ref: input / textarea / select / checkbox / contenteditable.
- `computer` по ref ИЛИ координате: click, scroll_to(ref), hover, zoom региона, key, type, drag.
- `get_page_text` (основной контент), `navigate` (url/back/forward), вкладки (list/create/close/select),
  `resize_window`, консоль и сеть для отладки, загрузка файла, запись GIF.
- `browser_batch` — несколько действий одним вызовом.

## Как делить работу (до 5 агентов)
Раунд ревью (параллельно, каждый — несколько углов: корректность, гонки, безопасность, скорость, общий случай):
1. **GUI-руки** (`apps/client/main/actuators/*`, фасады в `packages/tools`, хендлеры `brain/tools/handlers/act.ts` и др.)
   против эталона computer use / Windows-MCP.
2. **Браузерные руки** (расширение + `handlers/browser.ts` + `web_*`) против эталона Claude in Chrome.
3. **Петля и арсенал** (`brain/agent/loop/*`, схемы и описания инструментов, горячие/холодные, персона, навыки) — как
   модель пользуется руками: число раундов, лишние tool_load, verify-долг, где модель «врёт готово».
4. **Голос, скорость, проактив** (`voice/pipeline.ts`, подписка/SDK, метрики).
5. **Контроль** — второй раунд по правкам волны (свежие фиксы — главный источник следующих дефектов).
Итог ревью — `docs/REVIEW_2026-09-2X.md`: вердикт, находки (файл:строка, сценарий, серьёзность), план волн.

## Грабли (из опыта этой недели)
- Фикстура теста = реальная форма входа (схема шлёт `combo`, гейт читал `key` — тесты молчали).
- Синтетический Enter не жмёт нативные элементы; двойной click переключает галочку обратно.
- Селектор в снимке обязан быть уникальным в своём корне (radio Moodle делили один name).
- PowerShell: обратная кавычка в строке в двойных кавычках — escape (`` `r `` = CR). Тексты — файлом.
- Не хардкодить сценарии под сайт/программу: знание — данные (навыки, рецепты).
