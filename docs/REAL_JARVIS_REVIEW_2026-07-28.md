## Вердикт одной строкой

Фундамент честности/инструментов/безопасности — сильный и глубоко отревьюенный. До «реального
Джарвиса» не хватает **пяти столпов**: (1) он не живёт сам и молчит о своей смерти, (2) не отвечает
за <1 с, (3) не умеет задачи длиннее 4 минут и «когда X — сделай Y», (4) не помнит структурно
(20 строк FIFO) и не копит опыт, (5) не существует вне ПК. Живое доказательство пункта (1):
последний server-лог — 2026-07-25, на дату ревью сервер лежит **третий день** без единого сигнала.

## P1 — сильно мешает каждый день (26)

[L]
- **Чужой звук командует и перебивает**: loopback-AEC (WASAPI/desktopCapturer reference) не начат; speaker-gate готов (sherpa ready, voices:1), но `JARVIS_SPEAKER_GATE=0`. Мат в Discord запускал макрос; громкая ТВ-фраза ≥200 мс ложно перебивает. [L]
- **Присутствие в звонках — кода ноль**: планы 5 инкрементов (VB-CABLE, call_mode, слух собеседника) с 2026-07-12; `call-bridge/**` пусто, grep call_mode/makeSinkPlayer = 0; блокирующий зонд Process Loopback не пройден. [XL]

### Агент-петля
- **Нет subgoal-ledger**: прогресс/терминал держатся на скаляре `anyMutateSucceeded` (`index.ts:1361`); мульти-элементная задача закрывается на 3/5 без честного отчёта; stepLabel — индикация шага, не реестр подцелей. [L]
- **Hard-порог контекста убивает задачу** вместо observation-masking старых re-fetchable дампов (`index.ts:1737-1746` → fail); context rot деградирует с ~50K. [M]

[M]
- **Единственный LLM-провайдер без фолбэка и офлайн-очереди** (критик): аутэйдж Anthropic = весь мозг нем, команды не буферизуются «выполню, когда вернётся»; альтернативного LLM-пути в коде нет (`anthropic.ts:424` stub). [L]
- **toolEffect MCP — эвристика по имени** (`error-voice.ts:109-121`): `think` = mutate (ломает masked-failure), мутирующий `get_*` = neutral (обходит гард ложного «Готово»). Признанный последний кусок MCP-контракта, блокирует Фазу A relay-серверов. [S]

- **«Своя среда» не начата**: persistent SDK-сессия/world-model/WinEvent-подписка — «главная задача следующей сессии» по NEXT_SESSION; code_run клампится 180 с (`code-runner.ts:49-52`) — ломает контракт «1 раунд = вся задача» на долгих сценариях, killTree посреди GUI. [XL]
- **jarvis SDK слеп к браузеру**: `browser.*` вне BRIDGE_ALLOWED_KINDS (`act-bridge.ts:36-58`) — смешанные «десктоп+веб» задачи снова распадаются на N LLM-раундов; read-only browser в SDK — не принятое решение владельца. [M]
- **SoM-грундер для UIA-слепых окон/canvas не начат** (P0 глобального плана; OmniParser/UI-TARS — только в доках): игры = скриншот+OCR+слепые координаты через 30-с escape-hatch. [L]
- **Клиентский раннер навыков**: needsLlm-эскалация — no-op (M4+), cancel-токен — заглушка (M8): реплей 90–130 с неотменяем («Отмени!» доигрывает), в протоколе нет cancel-команды. [M]
- **Готовые веб-руки на полке**: AX-Ref/browser_batch/site-recipes за выключенным флагом (`JARVIS_BROWSER_REF` нет в боевом .env); несколько волн правок background.js ни разу не смоукнуты reload'ом в живом Chrome — неизвестно, работают ли telegram_send/browser_act сейчас вообще. [M]
- **Дубль отправки при «доставлено-но-таймаут»** (аудит-2 [9] открыт): sentKeys/markSent — только на result.ok; нужен reserve-then-release. Для писем людям — репутационный провал. [M]

- **Пока владелец за ПК — физические руки заблокированы** (USER_BUSY, порог 4 с): GUI-задачи не делаются большую часть дня; реальный Джарвис работает параллельно (второй desktop/сессия или тотальный перевод на бесшумный UIA). [XL]

### Память и опыт
- **Эпизодной хроники нет, консолидация неполна**: сон-цикл пишет только kind=fact из хвоста 40 реплик, триггер — лишь первый коннект дня (клиент на WS сутками не консолидируется); задачи ретенятся 6 ч, working — 12 ч: «что я делал в пятницу?» невозможен; противоречия фактов не ищутся. [L]
- **e5-small — потолок всей семантики**: recall/дедуп/дубль-гейт/авто-реплей живут на сжатой шкале (несвязанное 0.75–0.79 у порога 0.82); костыли (platform-boost, полярность) признаны пределом; трек «e5-large/реранкер» не начат (grep — 0). [L]
- **Опыт не копится**: авто-запись site-recipes мертва (только seed), selfLearnSkill гейтится успехом — провал не оставляет урока; подавленный навык (failCount≥3) — необратимая ловушка (снять может только recall, которого больше не будет). [L]

### Проактивность
- **Проактив-инфраструктура мертва**: ProactiveHub/salience/NudgeQueue построены и протестированы, но `emit()` никто не зовёт; все TriggerSource — пустые start() с TODO(M5); майнера привычек нет — инициатива = поллинг 2 ambient-источников. [L]
- **Календаря и почты нет вовсе**: ни провайдера (STATUS ссылается на несуществующий calendar.ts), ни IMAP/Gmail/Outlook (grep — 0) — «встреча через 20 минут» и «пришёл счёт» невозможны в принципе. Конвейер гардов §14 переиспользуем — не хватает самих интеграций. [L]
- **Бытовой минимум отсутствует**: повторяющихся напоминаний нет (Reminder — один fireAt, grep recurring — 0); утренний брифинг = одна фраза приветствия; «завтра позвонить маме» не превращается в reminder/obligation. [M]
- **Сенсор «микрофон занят звонком» — вечный false**: setMicBusy не вызывается никем; reminders/watch идут urgent → проактив говорит поверх созвона. Убивает доверие. [M]

### Безопасность и приватность
- **Секреты не защищены от code_run**: денилист — только в fs_*; `python -c open('.env')` проходит; мастер-ключ — plaintext-hex с мёртвым на NTFS mode 0o600 (`crypto.ts:62`), без DPAPI/icacls. [XL]
- **fs_write/edit/append/move — без confirm** (осознанно, но несогласованно с §14): `fs_write{content:''}` уничтожает документ молча, fs_delete того же файла спросил бы; опасно при prompt-injection. [M]
- **Данные третьих лиц в US-облака без маскировки/политики** (критик): screen_capture шлёт полный PNG (банковские страницы, чужие переписки) без редакции — redact() существует только в action-log; всё listening-аудио (голоса гостей) — в Deepgram; 152-ФЗ не упомянут нигде. Для single-user — осознанный риск, для hosted — блокер. [L]

### UX и эксплуатация
- **Нет кнопки «выключить микрофон»**: честный mute есть в main (IPC `preload:37`), но UI его не зовёт — muteBtn глушит только озвучку. Always-on без mic-kill-switch. [S]
- **Клиент без durable-логов и крашрепортов**: вся клиентская половина (аудио/VAD/wake/актуаторы/реконнекты) пишет в закрытую консоль — «вчера не слышал» диагностически слеп (та же слепота, что аудит закрыл для сервера). [M]
- **Health-индикация = online/offline, онбординга нет**: «жив, но оглох» неотличимо; орб безусловно «Слушаю» до коннекта и без прав микрофона (`renderer.ts:349-352`) — враньё о готовности. [M]
- **Эксплуатация слепа**: post-deploy smoke нет (CI нет вовсе — `.github/workflows` пусто), metrics.jsonl без анализатора (в data/logs — ручные _agg.txt), латентности без перцентилей/SLO, регресс стоимости не детектится (11% трат на smalltalk нашли ручным разбором). [M]
- **COGS/SpendGuard неполны**: STT-минуты и TTS-символы (≈$10/мес Heavy) не метрятся; watch-checker (LLM-цикл, тик до каждых 30 с сутками) — без spend.recordUsage, мимо месячного потолка; TradeExpert ведёт локальный this.spent мимо SpendGuard — класс дыры, закрытый для сон-цикла. [M]
