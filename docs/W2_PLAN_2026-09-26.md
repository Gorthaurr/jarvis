## 1. Ключевые решения

1. **Рубеж в точке инжекции.** Все мутирующие RPC сайдкара идут через `inject.ts`: type, key, click, mouse, invoke, вставка через клавиши. Рубеж — три судьи по порядку:
   - **self** — своё окно, неодобряемо;
   - **secret** — §0, неодобряемо;
   - **commit** — §14, одобряется грантом.

   Цель судится по **найденному** элементу и **реальному процессу**:
   - для handle — pid элемента;
   - для точки — окно под точкой по z-order;
   - для клавиатуры — передний план.

   Подстановки «иначе — передний план» для мыши и UIA нет. Процесс неизвестен → fail-closed только для кандидатов в коммит и §0.
2. **Коммит задаётся allowlist'ом** (`@jarvis/shared`, данные). Закон CLAUDE.md: «денилисты неполны».
   - **Клавиши:** вне `SAFE_KEYS` — коммит. Space и Enter судятся по элементу в фокусе: кнопка → `click:<имя>`.
   - **Элементы в messenger/bank/edo:** вне списка безопасных целей → подпись и одобрение.
   - **Браузер и прочие категории:** `COMMIT_WORDS_RE`.
   - **Удалённый доступ и ВМ:** через одобрение идут только клавиши.
3. **Одобрение = гранты** `{signature, process, hwnd?, count}` + `expiresAt`. Они живут только в ALS-области серверной команды.
   - У моста, реплея и локального UI области нет → fail-closed.
   - Грантов «по категории» нет.
   - Подписи на обеих сторонах считает одна функция из shared, это закреплено контрактным тестом.
4. **Браузер через GUI — категория web.** Сервер судит живую вкладку через `tabList`:
   - хост безопасный → грант без вопроса;
   - хост рискованный или неизвестный → вопрос.

   Мост и реплей → отказ «используй browser_act».
5. **Повтор после `needsApproval` — ровно один.**
   - Батч продолжается с шага k (`steps.slice(k)`).
   - Если часть действия ушла (injected) → `uncertain`, без повтора.
   - Текст вопроса строит сервер: что, кому, в каком окне. Строки с экрана — недоверенные и чистятся.
6. **Кадры вместо `lastMapping`.**
   - Координаты модели всегда относятся к кадру задачи.
   - Датчики (OCR, bbox) отдают координаты в системе полного кадра задачи.
   - Неизвестный кадр → честная ошибка.
   - `space:"screen"` остаётся только для SDK и макросов §8.
7. **Исполнение серий.**
   - `act{steps}` раскрывается на сервере; каждый шаг проходит через `dispatchTool` со всеми гейтами.
   - Стоп раунда: после провалившейся мутации остальные мутации раунда не исполняются.
8. **Кап кадра — данные по семейству модели**, без флага. На high-res по умолчанию 1080p-класс, деталь добирается зумом.
9. **ActionCommand собирается по allowlist полей схемы** инструмента. Модельные `space`, `approval`, `commitApproved`, `expectedForeground` и любые будущие служебные поля в команду не попадают.

   - Отказ владельца → `gateDeclined`.
   - Повторный `needsApproval` → честная ошибка, третьего вопроса нет.
   - web-категория с безопасным хостом → грант без вопроса.
   - **Контракт:** готовый ToolResult отдаётся до `actResult`; `actResult` код `denied` не трогает.
7. **S-7.**
   - Отправка: `timeout`/`disconnected` → `uncertain`.
   - `outbound`: статус `uncertain`, без `markSent`.

## 9. Поправки критиков: принятые с изменениями и отклонённые

**Принятые без изменений:**
- безопасность: №1, №2, №3, №5, №7, №8, №10, №11, №12, №14, №15, №16, №17 (ALS и URI);
- осуществимость: все пункты §0–§5, кроме перечисленных ниже.

Приняты с изменениями или отклонены:

| Поправка | Решение | Причина |
|---|---|---|
| Исходный план: процесс «иначе — передний план» | **отклонено** | это обход (безопасность №3); заменено атрибуцией по pid, точке и z-order |
| Исходный план: «одобрение = категория + процесс, если известен» | **отклонено** | заменено грантами (безопасность №6) |
| Исходный план: G-11 запрещает в своё окно только клавиатуру | **расширено** | любая мутация в свой процесс неодобряема (безопасность №1) |
| Исходный план: переписать `commit-guard.ts` | **изменено → удалить** | его заменяет рубеж; тесты переписываются на рубеж |
| Исходный план: гейт «≥ 3136», критик — «≥ 3185» | **изменено** | замер: 3187 зелёных и 3 красных (+ `incidents`, мс-коллизия); гейт по именованному списку |
| Безопасность №1: защита в глубину в renderer (физический ввод ≤ 1 с) | **перенесено в C# (§6)** | `isTrusted` истинен у любого SendInput; отличить можно только по `LLKHF_INJECTED` |
| Безопасность №1: «точка в bounds своего окна → отказ» | **изменено** | основной суд — верхнее окно по z-order; bounds только как фолбэк, иначе ложный отказ, когда своё окно позади цели |
| Безопасность №3: перебор всех окон по z-order | **изменено** | «active», затем ≤ 6 верхних окон и общий дедлайн — цена UIA-вызовов |
| Безопасность №4: пересъёмка на любой устаревшей записи | **изменено** | только в рискованном процессе и только если старая метка признана безопасной — иначе вопрос будет и так |
| Безопасность №6: срок около 60 с | **изменено** | срок = таймаут команды-носителя (≤ 130 с); одноразовость держит счётчик |
| Безопасность №7: Space и Enter по элементу в фокусе | **сужено** | только в рискованных процессах — цена `read.screen` |
| Безопасность №9: буфер на hwnd | **изменено** | эпоха фокуса без `window.list` (feasibility №15: «W» — ноль вызовов); для Луны копятся только цифры и разделители |
| Безопасность №13: select/toggle «в диалоге» | **изменено** | модальность без C# не узнать; расширенные слова (переслать, поделиться, позвонить; да/ok — в bank и edo) |
| Безопасность №14: удалённый доступ → `unknown` для всего | **сужено** | только клавиши: внутрь удалённой сессии UIA не видит, клики судить нечем |
| Осуществимость 1.4: поле `startAt` в протоколе | **отклонено** | серверный `steps.slice(k)` проще и не меняет раннер |
| Осуществимость 1.5: ранняя проверка A по имени от B | **принят второй вариант** | ранняя проверка только клавишная; клики судит рубеж; P0 даёт настоящий `FoundTarget.name` |
| Осуществимость 3.7: «имя не распознано → одобрение только по категории» | **отклонено** | противоречит безопасности №6; вместо этого вопроса заранее нет, клиент спросит через `needsApproval` с реальным процессом |
| Исходный §6: «сверить живьём, что старый сайдкар игнорирует лишние поля» | **снято** | проверено статически (`Ipc.cs:58-65`) |
