# Контекст для Codex

Перед изменениями прочитай `docs/HOW_IT_WORKS.md`, затем `CLAUDE.md`: это действующая карта проекта, несмотря на старое имя.
Общайся с Антоном по-русски. Он переходит с Claude на Codex и не хочет платить за API-ключи.
Основной remote: `https://github.com/Gorthaurr/jarvis.git`. Работай внутри этого существующего репозитория.
Крупную работу можно по просьбе Антона делить на отдельные задачи Codex. Каждой передавай цель, точный путь,
актуальное состояние, ограничения, нужные файлы и критерии готовности; не рассчитывай на общую историю чатов.

- Личный бесплатный профиль: `infra/run-no-api.ps1 -Brain codex|local`. Codex использует вход ChatGPT и общие лимиты
  подписки; Ollama и Whisper/Windows TTS работают локально. Не подключать платный fallback без прямого запроса.
- Контур выполнения команд, подтверждения, отмена и честность исхода остаются в Jarvis. Ответ модели сам по себе
  не доказывает выполненное действие. У отправки различай «ушло», «не ушло» и «неизвестно».
- Не перезаписывай незакоммиченную работу. 167 прежних untracked-файлов лаборатории сохранены без правок
  в WIP-коммите `bf0dc01`; резервная копия — `../_probe/codex-migration-baseline-20261006/untracked`.
- По поручению Антона от 06.10.2026 контролируй переданные отдельным задачам работы и сохраняй завершённые
  изменения коммитами в GitHub. Перед записью проверяй занятость файлов другой задачей и состояние ветки.
  Не коммить ключи, `.env`, модели, логи или данные пользователя. Отправляй рабочую ветку без force-push;
  известные провалы проверок явно указывай в описании, не выдавай WIP за готовое к слиянию изменение.
- Новые исходные модули держи до 150 строк. Проверяй изменённый механизм и реальные границы, не форму реализации.
- Для стенда используй `infra/lab/no-api/brain-smoke.ts`: модель и gateway реальные, ПК виртуальный.
  `voice-smoke.ts` проверяет синтез и распознавание файла; это не проверка микрофона, KWS или реального GUI.
- Изменение архитектуры отражай в `CLAUDE.md`, механики — в `docs/HOW_IT_WORKS.md`, историю — в `docs/CHANGELOG.md`.

Конфигурация основного ПК сохранена в глобальном `~/.codex/AGENTS.md`. Перед тяжёлым запуском измеряй свободную VRAM/RAM.
